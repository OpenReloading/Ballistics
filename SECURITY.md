# Security policy

Report a vulnerability in OpenReloading privately, so it can be fixed before it is public.

## Supported versions

OpenReloading is before 1.0. Only the `main` branch and the latest release receive fixes.

## Reporting

Use [Report a vulnerability](https://github.com/OpenReloading/Ballistics/security/advisories/new) on the Security tab of this repository. Do not open a public issue or pull request for it.

Include:

- what is affected (package, page or API route) and the version or commit,
- the steps to reproduce it, with the smallest input that shows it,
- what an attacker gains.

## What to expect

Reports are handled on a best-effort basis by a small team, with no promised response or fix times. You get an answer in the advisory thread, and a fix is published with credit if you want it.

The app's results are simulations, not load data: a wrong calculation is a bug to file as an issue, not a vulnerability.
