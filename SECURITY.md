# Security policy

## Supported versions

Only the latest release receives fixes while the project is in early alpha (0.0.x).

## Reporting a vulnerability

Report it privately through [GitHub private vulnerability reporting](https://github.com/OpenReloading/Ballistics/security/advisories/new), not as a public issue, a discussion or on Discord. Include the affected version, the component (web app, API, container image) and the steps to reproduce. The maintainers answer in the advisory and publish it with the fix.
