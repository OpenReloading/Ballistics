# `@rangefoundry/importers`

Parsers that turn chronograph exports, pressure histories, spreadsheets, load files and the RangeFoundry JSON and CSV files into candidates: a session, or a record without the id and save time the caller gives it (`id` is `idOfKey(key)`). The readers report a skipped cell or field as a code with its values (`{ code, params }`) for the caller to word, and refuse a file with a `ReaderError` that carries such a code. They take text or a workbook the caller has read, and do no I/O. The [table import](../data/table-import.md) page describes the table formats.

## Install

```sh
npm install @rangefoundry/importers
```

It installs `@rangefoundry/schema` with it. Each library has its own [Semantic Versioning](../release.md#versions) version.
