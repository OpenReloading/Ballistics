# Issue tracker: none in this repository

This repository takes no issues for agent work: tasks, proposals and findings are tracked outside it.

- Each task names its work item and how to report; work from the task.
- Open, edit, label or close no issue here, and take no task from this repository's issues. List a new finding or proposal in your report instead.
- When a skill says "publish to the issue tracker", put the text in your report. When it says "fetch the relevant ticket", use the task you were given.

## Pull requests as a triage surface

**PRs as a request surface: no.** _(`/triage` reads this flag.)_

Pull requests are where the work lands: the task's pull request, reviewed and merged as [CONTRIBUTING.md](../../CONTRIBUTING.md) describes.
